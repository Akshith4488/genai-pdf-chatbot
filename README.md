# GenAI DOC Chatbot

An AI-powered document assistant built using Streamlit, LangChain, and Groq LLM APIs.

## Features
- Upload PDF documents
- Upload Word documents (.docx)
- Ask questions from uploaded files
- AI-generated answers using LLMs
- Secure API key handling using .env

## Technologies Used
- Python
- Streamlit
- LangChain
- Groq API
- OpenAI SDK
- PyPDFLoader
- python-docx

## Supported File Types
- PDF
- DOCX

## Run Project

Install requirements:

pip install -r requirements.txt

Run app:

streamlit run app.py
